\subsection*{Four defensible presentation statements}
\begin{enumerate}
\item \textbf{Integration:} Ten historical sequence records report 50 successful outcomes across five ERPNext operations.
\item \textbf{Transformation:} Seven of eight historical structural rows pass all checks, with a documented response-mapping/oracle limitation.
\item \textbf{Governance:} Three recorded role cases match expectations; selected boundary behavior is observed, not fully validated.
\item \textbf{Performance:} One read-only demo run completes 100 calls with 361 ms median and 662 ms p95 client latency under paced ten-call bursts.
\end{enumerate}
