## bridgectl cache flush

Delete cache entries

### Synopsis

Manually invalidate cache entries stored by the configured cache backend.
You can target a specific tool by name, an entire module using the --module flag, 
or clear the entire cache with --all.

```
bridgectl cache flush [tool] [flags]
```

### Examples

```
  bridgectl cache flush finance.get-invoices
  bridgectl cache flush --module hr
  bridgectl cache flush --all
```

### Options

```
  -a, --all             Flush everything
  -h, --help            help for flush
  -m, --module string   Flush entire module
```
